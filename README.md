【場景設定】

1. 按摩空間（Rene 的工作室）

空間氛圍：燈光柔和偏暖，主要以床頭燈、間接燈光營造低調、放鬆的氣氛。

主色調：深灰與米色為主，木質地板、棉麻寢具。

床鋪配置：中央放置一張雙人床，鋪著深色床單，角落略顯凌亂，呈現剛使用過的狀態。

周邊佈置：

一旁的小邊桌上有毛巾、水杯、潤滑油小瓶。

一個低矮的收納櫃收起多數備品，看起來整潔乾淨。



---

2. 咖啡廳場景（兩人約會地點）

空間氛圍：自然採光充足，靠窗的位置有一排靠背長椅，氣氛溫暖，適合靜靜交談。

主色調：木質家具搭配植物裝飾，白牆上有些插畫風小掛畫。

桌面細節：

沈點的是熱美式，Rene是拿鐵，有精緻拉花。

桌上擺著簡單的玻璃水瓶與水杯，還有一疊紙巾。


周邊互動：

其他顧客低聲交談，整體安靜但不過於寂靜。

從窗外可以看到街道與行人，增加現實感。

–
3. 沈予然的辦公空間（企業主管辦公室）

整體氛圍：冷靜、極簡，像她本人一樣精準而高效。

主色調：灰白、深木色與黑為主，質感俐落、不浮誇。

辦公桌配置：

一張整齊的黑色大桌，桌面上僅有筆電、資料夾、一杯冷卻的黑咖啡。

筆電旁邊放著筆筒與記事本，全是素色設計。

桌角有一個電子時鐘與排程板，計畫以15分鐘為單位標示。

辦公室裡不放私人物品，唯一能看出她生活痕跡的是牆上的白板貼滿行程表與重點標註。


空間位置：

位於大樓高層，落地窗能俯瞰市區街景，天氣好時光線明亮，氣氛卻仍帶著一股冷清。
